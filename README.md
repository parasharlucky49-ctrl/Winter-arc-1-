# WINTER ARC — Android App

Branded Android wrapper for the Winter Arc 90-Day Tracker HTML app.

## Branding included
- Custom WINTER ARC launcher icon (purple/dark WA monogram)
- Android 12+ native splash branding
- Consistent branded splash screen on older Android versions
- WINTER ARC app label and dark/purple theme
- 90 DAYS • DISCIPLINE • CONSISTENCY subtitle

## Build
Open this folder in Android Studio, let Gradle sync, then use **Build → Build APK(s)**.

The tracker is bundled locally in `app/src/main/assets/index.html`, so its core features work without a server.
